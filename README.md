# Velocity Releases

Download [VelocitySetup.zip](https://github.com/andre334424444/velocity-updates/releases/latest/download/VelocitySetup.zip), extract it into a writable folder, and run **Launch Velocity.cmd**.

The first launch installs the current application, GPU runtimes and encrypted models. Later launches check for updates automatically. A valid Velocity license is required to use the application and models.

This repository contains distribution files only. Release metadata and downloaded application files are verified by the launcher.
